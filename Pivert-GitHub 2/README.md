# Pivert — prototype

Статический прототип. Сборка и установка зависимостей не требуются.

## Публикация
1. Создайте репозиторий GitHub, например pivert-prototype.
2. Загрузите содержимое этой папки в корень репозитория: index.html, css, js, assets и .nojekyll. Сам ZIP загружать не нужно.
3. Откройте Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Ссылка сайта появится в Settings → Pages.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Кабинет
Добавьте ?admin=1 к адресу сайта. Это демонстрационный локальный редактор без авторизации. Изменения, фото и GLB сохраняются только в браузере на этом адресе, не обновляют репозиторий и не видны другим посетителям. Изменения на localhost автоматически не переносятся: используйте экспорт/импорт резервной копии для переноса в свой браузер.

Форма заявки открывает почтовое приложение. Автоматической отправки на сервер нет.
Шрифты, часть фотографий и библиотеки 3D загружаются из интернета.
